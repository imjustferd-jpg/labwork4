# Лабораторна робота № 4. Веб-програмування

**Тема:** Семантична реорганізація веб-документа та оцінка його доступності (Accessibility)  
**Виконав:** Бондарчук П. С.

## Опис проєкту
У цьому репозиторії представлено реорганізований HTML-документ. Несемантична структура («div-soup») була перероблена за стандартами HTML5.

### Впроваджені покращення:
* Використано семантичні теги: `<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`.
* Додано посилання пропуску (Skip Link) для навігації з клавіатури.
* Налаштовано чітку ієрархію заголовків (`h1`-`h3`).
* Впроваджено ARIA-атрибути (`aria-label`, `aria-labelledby`) для покращення доступності екранами зчитування.
* Для блоку FAQ використано нативні інтерактивні теги `<details>` та `<summary>`.
