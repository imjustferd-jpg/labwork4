Методичні рекомендації з одиниць вимірювання в CSS

Навчальний матеріал з дисципліни «Веб-програмування».

Загальні відомості про CSS-одиниці

CSS використовує одиниці вимірювання для задання ширини, висоти, відступів, розмірів шрифтів та інших властивостей.

Абсолютні одиниці

До абсолютних одиниць CSS належать px, cm, mm, Q, in, pt і pc.

Відносні одиниці

До відносних одиниць належать em, rem, %, vw, vh, vmin і vmax.

Одиниці для розмітки

Під час побудови веб-сторінки важливо розрізняти фіксовані та гнучкі розміри.

Практичне використання

Корисна інформація

Перевірити CSS можна за допомогою інструментів розробника браузера (F12).

Часті запитання

Що таке px?

px — це логічний CSS-піксель.

Для чого потрібен rem?

rem використовується для відносного масштабування відповідно до розміру шрифту кореневого елемента.
